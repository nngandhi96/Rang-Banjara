# Rang Banjara - Artisanal Silver & Brass Jewellery

A luxury, artisanal e-commerce web platform for handcrafted Banjara and tribal jewellery (chokers, jhumkas, payal, statement rings, and cuffs).

## ✨ Features
- **Artisanal Catalog & Filtering**: Seamless category filtering (Necklaces, Earrings, Rings, Payal).
- **Interactive Shopping Bag & Wishlist**: Real-time sliding drawer with instant updates and local storage state.
- **Quick View & Search**: Instant modal previews and comprehensive search across collections.
- **Direct WhatsApp Integration**: Floating bottom-left WhatsApp quick-action button (+91 7303474030).
- **Responsive Luxury Aesthetic**: Built with Tailwind CSS, FontAwesome, and Google Fonts (Playfair Display & Plus Jakarta Sans).

## 🚀 Getting Started

To view the project locally:
```bash
# Start a local HTTP server
python -m http.server 8000
```
Then open [http://localhost:8000](http://localhost:8000) in your browser.
